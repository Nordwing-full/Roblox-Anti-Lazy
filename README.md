# Roblox-Anti-Lazy
I decided limit myself for full of a games, and considering that in Roblox you can both play and develop your own places, I made this script for closing my Roblox Player app if I not in my place.(This project was created primarily for learning purposes.ALL COMMENTS IN CODE ON RUSSIAN)
---

RUS: Это мой первый проект который я осознанно и заинтересованно реализовал в программировании и выложил на публику более менее оформленно, этот проект учебный и создан он только для того что бы объяснить новичкам как работает и читается код, как можно объединить определённые библиотеки в одном лёгеньком проекте, суть проекта максимально проста, при старте программы запрашивается ваш никнейм в роблоксе, и если режим в который вы зашли не является вашим творением то роблокс закрывается.

ENG: This is the first project I’ve developed with genuine intent and interest, and published in a reasonably polished state; it is an educational project designed to show beginners how code works and how to read it, as well as how to implement specific libraries in a simple project. The concept is straightforward: upon startup, the program asks for your Roblox username, and if the game mode you have joined was not created by you, the application closes.
